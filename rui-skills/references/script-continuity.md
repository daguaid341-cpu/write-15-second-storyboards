# 整剧理解与连续性工作流

## 剧本接收

接受一次上传的完整剧本（TXT、PDF、DOCX 等）或分批粘贴的章节。先确认实际可读取范围及版本；分批输入时按集号、场次、版本顺序记录已读范围，未收到的部分标为待补。不要将剧本正文写入技能目录，技能只保存工作方法。若用户希望下次继续同一项目，建立并维护可持久读取的项目资料文件；下次生成前读取最新剧本及项目资料，不把聊天记忆当成唯一来源。源文件与资料有冲突时，以用户最新明确修改和最新剧本版本为准，列出无法判断的冲突。

长剧本按集/场阅读并累积结构化资料；不要仅依赖首尾摘要。每场保留：集号/场号、日夜内外、地点、出场者、戏剧目标、情绪起伏、进入状态、退出状态、事件与台词、邻接场次。建立全剧时间线和人物关系，区分故事发生顺序与剪辑顺序。只推断有证据支持的事实，并标明剧本未确定的设定。

## 项目资料的最小结构

| 表 | 必备字段 |
| --- | --- |
| 场次索引 | 场次 ID、集号、时间/地点、人物、剧情目标、前后场、来源页/段 |
| 人物状态 | 身份与固定外貌、当场服装发型、已知信息、情绪目标、伤痕与随身物、进出场 |
| 人物表演依据 | 触发事件/台词、关系与知情范围、当场目的和顾虑、潜台词、情绪转折、可见微动作与视线目标、反馈时点、来源及推断标记 |
| 场景空间 | 不变的入口/出口、门窗、家具、光源、可通行路线、摄影轴线与可拍机位 |
| 场景出场记录 | 统一场景 ID 与别名、全剧剪辑顺序中的首次出现场次、已读范围内出场次数、全剧频率（低频/高频/待确认）及来源、已使用的展示镜头与场景辨识细节 |
| 道具与物理状态 | 物品归属、握持手、具体位置、开启/关闭、完整/破损、数量、变化发生镜头 |
| 镜头交接 | 上组末帧 → 本组首帧、本组末帧 → 下组首帧；人物坐/站、面向、视线、手势、道具、声音、光照 |
| 设定与风险 | 既定镜头风格、禁止项、版本差异、证据不足处、待用户确定处 |

每一项写明来源（剧本场号、参考图、用户明确修订或合理推断）和最后更新时间。图片只锁定实际可见内容；画面外空间不能假定为已确认。

这些表用于内部连续性检查，不是要求把服装颜色款式、装修色板和结构逐项写入视频提示词。视频沿用资产引用，只写有来源且与当镜辨认、动作或连续性有关的细节；未确定的外观保持未指定，不从人物设定图模块自动补全。空间感检查通过已有空间的构图、景深、遮挡、光照和机位完成，不改造场景。

## 场景展示镜头：全剧出场顺序与频率

每次写视频分镜都先判断目标场景的出场状态，单场请求也执行。按观众看到的全剧剪辑顺序统一场景 ID 与别名，记录首次出现场次、已读次数、全剧频率及来源；回忆和插叙也按首次看见判断，故事时间另记。不把本集首次当成全剧首次，不自设高低频次数门槛，未读部分不得计为零。

| 已确定的场景状态 | 默认执行 |
| --- | --- |
| 全剧首次出现 | 安排大全景与移动氛围交代，可合为一镜；用已有场景展示空间规模、入口/通道、人物位置与光线。移动写明起点、路径、终点和进入人物戏的切点。 |
| 已出现、全剧低频再现 | 优先让已有动作特写带出辨识细节，不重复完整大全景，不用静态环境空镜替代动作。 |
| 已出现、全剧高频复用 | 通常直接进入人物或关系镜头，必要时才补方位；不在每集或每组重新定场。 |

首次规则优先于低频规则：即使该场景全剧只出现一次，也按首次展示。仅有片段且首现/频率未知时，注明已读范围与必要假设，不冒充全剧结论；可先完成其他镜头，只有判断确实影响用户指定的开场时才最小澄清。

本轮用户明确指定镜头范围、禁止大全景或要求固定监控等拍法时优先遵守，内部记录例外依据。已写出的合格环境镜头可计入，不重复添加；固定监控全景交代空间后，不为套移动模板让监控机位移动。开场钩子可以先出现，但首次场景仍需在该场景引入段完成必要的整体交代，不能一直拖进人物特写。

交付前逐场核对「出场判断及来源 → 对应镜号 → 是否完成展示或有用户例外」。首现镜头应实际看得清空间及人物位置，镜名叫全景但主体占满画面或背景全糊不算完成。缺失且无例外时先修正再交付；对白和动作时间不足时调整切镜或说明所需时长，不静默删掉展示或台词。内部记录即可，不强制向用户附检查表。不得为展示空间新增家具、道具、无因动作或改造参考场景。

## 多人场景预排

写人物表演前，从最新剧情文档的目标场与必要前后场提取表演依据，按主技能「人物画面细节：根据剧情推导表演」将心理变化落实为少量可见细节，直接写进镜头。区分剧本明确动作与合理表演补充；未读场次保持待确认，不借后续事实改变当场知情状态。关键转折补足说话者与倾听者的反馈时差，反应只分配给现场能听见或看见事件的人。

1. 在每个场次给人物稳定代号，先绘制文字化俯视站位：固定物件为坐标，谁在门边、桌哪侧、谁挡谁、通道在哪里。定义镜头所在轴线侧与人物视线目标；画面左右随机位而变，不作为唯一坐标。
2. 逐拍列出“谁行动 → 谁看到/听到 → 谁反应 → 谁移动 → 新站位”，包括背景人物在同一时间段的合理状态；多人同框不得让配角凭空消失或每个反打里换位置。
3. 跟踪进出画与遮挡：从哪扇门进、经过谁的前/后、是否有足够时间到达新位置；切到反打后检验左右关系、视线高度、朝向和光向。越轴若为有意设计，必须有中性镜头、可见跨越或明确重建方位。
4. 将对话时长、轮次、打断、动作时间和反应时间合计；30 秒装不下就拆为多组。每组复制足够的角色与场景锚点，避免生成工具只读当前一组时丢失前文。

## 穿帮检查清单

- 人物：面容、衣装、发型、湿度/伤痕；前镜手臂位置与后镜一致；只对知情人物赋予相应反应。
- 表演细节：微动作有剧情触发与人设依据；视线目标、姿态、空闲手和反馈顺序合理；无机械套用或过度表演，不用眼神颜色代替表演；关键细节在对应景别可见，时长与下一镜状态相容。
- 空间：门窗、家具、车辆与背景方向一致；镜头轴线、遮挡关系、人数和出入口不矛盾。
- 动作：关键动作有开始与完成；手里物品没有凭空换手、重复出现或消失；坐站转身和行走距离合理。
- 时间与声音：日夜、天气、光源与阴影方向一致；对白人声、画外声、脚步和动作音对位；无意外 BGM/字幕。
- 剪辑：跨组末帧与首帧明确相接；运动方向、视线、道具、服装、表演强度连续；回忆/插叙明确标识。
- 场景展示：首现与频率判断有来源；大全景、移动氛围或动作特写符合出场规则和用户本轮要求；氛围镜头不挤占对白或关键动作所需时间。
- 来源：有冲突时优先按用户最新明确指令，再按最新版剧本和参考图；绝不暗改对白或填充未经授权的重要剧情。

输出前针对高风险项做一次内部审查，修正能从来源确定的矛盾。无法确认且会决定分镜的冲突，仅询问最小必要问题，同时完成不受影响的场次。无法从提示词控制视频模型随机误差；对最终生成的视频还应逐帧复核人脸、手指、道具与空间连续性，发现问题后提供具体重生成提示词。
