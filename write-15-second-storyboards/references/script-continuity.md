# 整剧理解与连续性工作流

## 剧本接收

接受一次上传的完整剧本（TXT、PDF、DOCX 等）或分批粘贴的章节。先确认实际可读取范围及版本；分批输入时按集号、场次、版本顺序记录已读范围，未收到的部分标为待补。不要将剧本正文写入技能目录，技能只保存工作方法。若用户希望下次继续同一项目，建立并维护可持久读取的项目资料文件；下次生成前读取最新剧本及项目资料，不把聊天记忆当成唯一来源。源文件与资料有冲突时，以用户最新明确修改和最新剧本版本为准，列出无法判断的冲突。

长剧本按集/场阅读并累积结构化资料；不要仅依赖首尾摘要。每场保留：集号/场号、日夜内外、地点、出场者、戏剧目标、情绪起伏、进入状态、退出状态、事件与台词、邻接场次。建立全剧时间线和人物关系，区分故事发生顺序与剪辑顺序。只推断有证据支持的事实，并标明剧本未确定的设定。

## 项目资料的最小结构

| 表 | 必备字段 |
| --- | --- |
| 场次索引 | 场次 ID、集号、时间/地点、人物、剧情目标、前后场、来源页/段 |
| 人物状态 | 身份与固定外貌、当场服装发型、已知信息、情绪目标、伤痕与随身物、进出场 |
| 场景空间 | 不变的入口/出口、门窗、家具、光源、可通行路线、摄影轴线与可拍机位 |
| 道具与物理状态 | 物品归属、握持手、具体位置、开启/关闭、完整/破损、数量、变化发生镜头 |
| 镜头交接 | 上组末帧 → 本组首帧、本组末帧 → 下组首帧；人物坐/站、面向、视线、手势、道具、声音、光照 |
| 设定与风险 | 既定镜头风格、禁止项、版本差异、证据不足处、待用户确定处 |

每一项写明来源（剧本场号、参考图、用户明确修订或合理推断）和最后更新时间。图片只锁定实际可见内容；画面外空间不能假定为已确认。

## 多人场景预排

1. 在每个场次给人物稳定代号，先绘制文字化俯视站位：固定物件为坐标，谁在门边、桌哪侧、谁挡谁、通道在哪里。定义镜头所在轴线侧与人物视线目标；画面左右随机位而变，不作为唯一坐标。
2. 逐拍列出“谁行动 → 谁看到/听到 → 谁反应 → 谁移动 → 新站位”，包括背景人物在同一时间段的合理状态；多人同框不得让配角凭空消失或每个反打里换位置。
3. 跟踪进出画与遮挡：从哪扇门进、经过谁的前/后、是否有足够时间到达新位置；切到反打后检验左右关系、视线高度、朝向和光向。越轴若为有意设计，必须有中性镜头、可见跨越或明确重建方位。
4. 将对话时长、轮次、打断、动作时间和反应时间合计；15 秒装不下就拆为多组。每组复制足够的角色与场景锚点，避免生成工具只读当前一组时丢失前文。

## 穿帮检查清单

- 人物：面容、衣装、发型、湿度/伤痕；前镜手臂位置与后镜一致；只对知情人物赋予相应反应。
- 空间：门窗、家具、车辆与背景方向一致；镜头轴线、遮挡关系、人数和出入口不矛盾。
- 动作：关键动作有开始与完成；手里物品没有凭空换手、重复出现或消失；坐站转身和行走距离合理。
- 时间与声音：日夜、天气、光源与阴影方向一致；对白人声、画外声、脚步和动作音对位；无意外 BGM/字幕。
- 剪辑：跨组末帧与首帧明确相接；运动方向、视线、道具、服装、表演强度连续；回忆/插叙明确标识。
- 来源：有冲突时优先按用户最新明确指令，再按最新版剧本和参考图；绝不暗改对白或填充未经授权的重要剧情。

输出前针对高风险项做一次内部审查，修正能从来源确定的矛盾。无法确认且会决定分镜的冲突，仅询问最小必要问题，同时完成不受影响的场次。无法从提示词控制视频模型随机误差；对最终生成的视频还应逐帧复核人脸、手指、道具与空间连续性，发现问题后提供具体重生成提示词。
