# 操作演示：三人餐桌戏

> 虚构剧情与场景，不含真实用户剧本。

## 输入

```text
使用 $write-15-second-storyboards 写成一组 15 秒真人短剧视频提示词。
夜内公寓餐区，A 坐在靠玄关一侧，B 坐在桌子对面。C 从玄关进入，
走到桌边，右手把钥匙放在 A 和 B 之间。A 先看钥匙再看 C，
B 不知道钥匙的来历。镜头保持人物、餐桌和玄关的空间一致。
```

## 先核对的状态

| 时点 | A | B | C | 钥匙 |
| --- | --- | --- | --- | --- |
| 开始 | 靠玄关坐着 | 对面坐着 | 玄关外/入口处 | C 的右手 |
| 到桌边 | 原位，听见脚步 | 原位 | 桌边站立 | C 的右手 |
| 放下后 | 原位，先看钥匙 | 原位，看到放钥匙动作 | 桌边站立 | 两人之间的桌面 |
| 结束 | 看向 C | 看向钥匙 | 桌边站立 | 桌面静置 |

## 统一提示词

9:16 竖屏，夜内公寓开放式餐区。餐桌位于客厅与玄关过渡区，玄关为 C 的入口。暖色吊灯主照桌面和人物面部，窗外深蓝夜景仅作为后景层次。ARRI ALEXA 35 Open Gate，Zeiss Master Prime 35mm / 50mm / 75mm，24fps，180°快门，T2.0–T2.8，自然肤色。A 与 B 始终坐在原位，C 从玄关走到桌边后站定；钥匙在放下前始终由 C 右手持有，放下后始终位于两人之间的桌面。所有镜头处于既定轴线同一侧。无音乐、BGM和字幕，只保留脚步及钥匙接触桌面的同期声。

## 15 秒分镜

**0–4秒【中景｜桌旁朝玄关的斜侧机位｜35mm，T2.8｜固定】** A 坐在靠玄关一侧，B 坐在对面，两人位置由桌面分开。C 从玄关进入，右手握着钥匙沿通道走向餐桌。A 听见脚步后抬头；B 仍坐着，转头看向来人。切在 C 到达桌边。

**4–8秒【双人中近景｜同一轴线侧｜50mm，T2.2｜轻推】** C 停在桌边，右手从身侧抬到桌面，手腕越过桌缘，将钥匙放在 A 与 B 之间，手指松开后收回。A 的目光跟随钥匙落下；B 低头看到动作，却没有表现出了解钥匙来历。切在钥匙接触桌面后。

**8–12秒【A 近景｜桌边三分之四侧面｜75mm，T2.0｜固定】** A 看着桌上的钥匙停半秒，呼吸略顿，随后抬眼看向仍站在桌边的 C。她没有起身或触碰钥匙；画面下缘保留桌面与钥匙的位置关系。

**12–15秒【三人中景｜沿用首镜轴线侧｜50mm，T2.8｜固定】** A 仍坐在靠玄关一侧望向 C，B 坐在对面看着钥匙，C 站在桌边，右手已收回身侧。桌面钥匙不移动。保持三人关系到 15 秒末，为下一组留下明确首帧。

**约束条件：** 不换座、不越轴、不让钥匙凭空换手；C 不从画外瞬间出现在桌边；B 只能对看见的动作反应，不擅自增添知情台词；不新增第四人。

## 检查结果

- 时间：0–4、4–8、8–12、12–15 秒，完整覆盖 15 秒。
- 空间：玄关入口、桌边通道、两人座位和摄影轴线保持一致。
- 道具：C 右手持钥匙 → 放下 → 桌面静置，没有重复取放。
- 情绪：A 看到钥匙后才紧张；B 没有提前获知来历。
- 末帧：下一组必须从 A/B 坐着、C 站着、钥匙在桌上的状态接起。
