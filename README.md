# 15秒分镜提示词 · Screenplay-aware Storyboard Skill

将剧本、人物设定和场景参考转成**可直接复制的真人短剧视频提示词**。技能以 15 秒为一组，先理解剧本整体，再核对多人站位和镜头连续性，最后输出统一提示词与逐秒分镜。

> 这是编写与核查提示词的技能，不是视频生成器。它能够减少显著的剧情和镜头矛盾，无法保证下游模型生成的每一帧都没有穿帮。正式使用前还需检查生成成片。

## 能做什么

| 功能 | 具体行为 | 输出 |
| --- | --- | --- |
| 整剧理解 | 阅读一次上传或分批提供的剧本；区分已读与未读场次、版本和故事发生顺序 | 场次索引、人物关系、戏剧目标与情绪走向 |
| 连续性记录 | 跟踪人物外貌、服装、知情状态、伤痕、道具持有者、日夜天气、光源及每场进出状态 | 可供后续场次复用的项目资料 |
| 多人预排 | 以门窗、餐桌、车辆等实体为坐标，确认站位、运动路线、视线、摄影轴线、遮挡和配角反应 | 清楚的空间与动作链 |
| 15 秒分镜 | 按秒拆镜，写景别、机位、焦距、人物位置、微表情、连续动作、运镜、光源和切点 | 每组 0–15 秒完整提示词 |
| 多组衔接 | 将较长场次拆为多组，核对前组末帧与后组首帧 | 连续场次的多组提示词 |
| 穿帮预检 | 核对人数、进出画、道具换手、视线、光向、对白时长和人物知情范围 | 修正后的分镜与必要的待确认点 |

## 如何使用

在支持个人技能的 ChatGPT/Codex 环境中启用该技能，或将 `write-15-second-storyboards/` 作为技能目录导入；之后可以用 `$write-15-second-storyboards` 显式调用。仅复制 README 不会安装技能。

### 1. 导入剧本

上传 TXT、PDF 或 DOCX 剧本，或分集粘贴。示例请求：

```text
使用 $write-15-second-storyboards 阅读这份完整剧本。
先建立场次索引、人物与场景连续性资料，列出你确实读到的集数和场次。
暂时不要生成分镜；发现剧本版本冲突或关键设定缺失时标明。
```

技能不会自动把整部剧本写进自身文件。需要跨会话沿用时，让助手建立可持续读取的项目资料，下次工作时提供或指定最新剧本和资料。不要在公开仓库提交未获授权的剧本、人物参考图或私密项目资料。

### 2. 生成指定场次

```text
使用 $write-15-second-storyboards 生成第 3 集第 5 场。
参考已整理的剧本与人物设定，按连续的 15 秒组输出。
统一提示词保证场景和光影；分镜按秒写景别、机位、主体站位、动作链和反应。
重点核查三人站位、谁拿着钥匙、门的位置和组与组之间的末帧衔接。
```

### 3. 修改与复核

```text
第二组第 4 镜的人物从桌边瞬移到门口了。
只修改这段及必要的前后衔接，保留其他镜头与台词。
重新核对动作所需时间、摄影轴线和道具归属。
```

## 操作演示：三人餐桌戏

以下是**虚构示例**，不包含用户的实际剧本或图片。完整演示见 [examples/dinner-scene.md](examples/dinner-scene.md)。

**输入梗概：** 夜晚，A 坐在餐桌近门一侧，B 坐在对面，C 从玄关走来并把一把钥匙放在两人之间。A 先看钥匙，再看 C；B 一直坐着，尚不知道钥匙的来历。

**连续性锚点：** 玄关是唯一入口；A 与 B 不换座；C 从玄关步行到桌边；钥匙先在 C 右手，放下后位于桌面两人之间。A 的视线先落钥匙后落 C；B 只对自己看见的动作作反应。

**输出示意：**

```text
统一提示词：9:16 夜内，餐桌位于客厅与玄关之间。暖色吊灯照亮桌面与人物面部，窗外深蓝仅作背景。三人服装、餐具和椅子位置在全组保持一致。无音乐、BGM和字幕，保留脚步、钥匙落桌和指定对白的同期声。

0–4秒【中景｜桌旁朝玄关的斜侧机位｜35mm，T2.8｜固定】A 坐在靠门一侧，B 坐在对面。C 从玄关走向餐桌，右手握着钥匙；A 听到脚步抬眼，B 保持坐姿。切在 C 到达桌边。

4–8秒【双人中近景｜同一轴线侧｜50mm，T2.2｜轻推】C 停在桌边，右手从身侧移到桌面，将钥匙放在 A 与 B 之间，手指松开后撤回。A 的目光跟随钥匙；B 随动作低头，不提前表现出已知内情。

8–12秒【A 近景｜桌边三分之四侧面｜75mm，T2.0｜固定】A 先看桌上的钥匙，停半秒，再抬眼看 C；肩膀微微绷紧，没有站起。桌面一角仍可见钥匙，位置不变。

12–15秒【三人中景｜沿用首镜轴线侧｜50mm，T2.8｜固定】A 仍坐在靠门一侧，C 站在桌边，B 坐在对面并看向钥匙。以三人的新状态结束，下一组从此站位接起。
```

这组示例演示了道具状态从“C 右手持有”变成“桌面静置”、人物可见信息差和镜头间的站位继承。实际制作时会根据剧本对白长度、参考图和表演节奏调整镜头数与秒数。

## 边界

- 15 秒是单组长度，长场次可生成多组；长对白不会为了塞入 15 秒而被悄悄删去。
- 参考图只约束可见空间；未展示的背后结构必须标为待确认或合理假设。
- 输出前检查文本逻辑；实际视频仍需人工核查面容、手部、物件、空间与剪辑连续性。
